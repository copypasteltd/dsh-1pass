## 语言、布局与导航

1. 打开 DSH 自身的**语言／偏好设置**，选择 **English** 或**简体中文**。
2. 返回密码管理；文字跟随宿主 locale。1pass 没有独立的每库语言开关。
3. 阅读对应文档：[English](<gui-guide.md>)／[简体中文](<gui-guide-zh.md>)。切换文档语言不会自动更改应用语言。
4. 四个主入口是**首页、密码簿、云端同步、设置**。
5. 窄屏会把部分入口收进**更多**；这是按实际宽度折叠，不是功能消失。
6. 首页快捷操作与命令面板可以打开**安全检查、导入／导出、会话、活动、回收站、快速导入、本地备份、关于**。
7. 任务占用工作台完整内容区；**返回**回到打开任务的主页面。想留在 1pass 时，关闭任务即可，不必关闭 DSH 外层设置。
8. 页脚显示就绪／加载／错误／锁定／处理中；“状态不可用”不是空库证据。

标签页只记忆非秘密导航，不应把秘密、草稿与导入密码持久化到浏览器存储。
屏幕共享、剪贴板历史与浏览器扩展不在静态加密保护范围内，操作时另行注意。

## 创建、解锁与锁定

### 首次使用

1. 等待初始状态检查；失败时点**重试**，不要把失败误当成新空库。
2. 没有库时，输入非空**主密码**与确认，选择**创建密码库**。
3. 已有库时，输入原主密码并**打开密码库**；不要用创建另一个文件掩盖密码错误。
4. 弱密码提醒只是建议；真实使用仍应选择强且唯一的主密码并独立保管。
5. 表单只把值发送给本地宿主，不作为模型工具参数、URL 或浏览器存储条目。

### 会话期间与结束后

- **锁定密码库**后，需要重新打开才能继续读取／修改；在设置中选自动锁定间隔。
- 宿主重启会失去仅运行时保存的 GUI 解锁材料；需重新输入，或使用你主动配置的环境变量部署。
- 改语言／主题不会解密或迁移库。
- 单独启动的 CLI 不会自动取得 GUI 内存密钥，必须有自己的已授权密码输入。
- 不要把主密码粘贴进聊天／问题报告，也不要写进仓库配置行。

**预期结果：** 工作台加载摘要，显示真实活动库；解锁失败应保持失败状态，不能被助手描述成成功。

## 首页

首页是概览，不是第二套凭据存储。

1. 核对活动库名、条目数量、访问状态与本地加密标记。
2. 把健康／弱密码／重复／备份数字当作待检查线索，而不是安全证明。
3. 单条凭据用**新建条目**，本地多行内容用**快速导入**。
4. 快捷操作打开**安全检查、导入／导出、本地备份、会话、回收站**。
5. 查看最近活动；需要筛选和更多记录时进入活动任务。
6. 外部已授权写入后，显示陈旧可使用刷新。

首页卡片不会验证 SSH 密码是否正确，也不会证明云目标可写。

## 密码簿：搜索、筛选与行操作

### 找到目标条目

1. 打开**密码簿**，输入标题、用户名、主机、URL 或有用的元数据关键词。
2. 使用**类型**与**标签**缩小范围。
3. 按需组合**收藏、到期／过期、风险／问题**过滤；已知条目找不到时先清空这些条件。
4. 选择名称、最近修改、最近创建或智能／收藏优先排序。
5. 核对结果数；**加载更多**显示剩余行。当前可见一页不是完整库存。
6. 展开目标行，核对摘要和操作。标题可能重复，应检查身份／主机及可见 ID。

搜索／列表省略标准秘密字段，但元数据本身仍可能敏感；用户也可能误把秘密写进标题、URL 或备注，不能承诺任意元数据都无害。

### 有意使用行操作

| 控件 | 作用与注意点 |
|---|---|
| 星标 | 收藏／取消收藏，会修改条目 |
| 展开 | 展示详情，不会连接远程主机 |
| 编辑 | 把选定条目载入编辑器 |
| 复制密码／Key／令牌／卡号 | 读取相关值并放入剪贴板，注意历史记录软件 |
| 复制全部字段 | 更大的明文暴露范围，仅在全部字段均获准时使用 |
| TOTP | 生成短时验证码，使用前检查倒计时 |
| TOTP 设置链接 | 暴露长期设置密钥，不只是临时验证码 |
| 历史密码 | 查看旧密码；回滚会写库并归档当前密码 |
| 附件 | 列出／下载／移除；下载文件在库外是明文 |
| 克隆 | 连秘密一起新建副本，核对身份、删除无用副本 |
| 删除 | 软删除到回收站，不擦除备份／历史 |

部分操作在 **⋯ 行菜单**或展开详情中，随类型、锁库／只读状态可用。
风险／到期徽标可打开条目修正。三颗星是密码／PIN 强度建议，不给机器生成的 API Key 或私钥评分。

### 多选

多选模式支持批量收藏、加标签、删除与所选字段 CSV 导出。执行前检查所选数量及筛选范围。
批量删除仍是软删除；即使列表遮罩，CSV 也可能包含明文密码。

## 凭据编辑器与模板

打开**新建条目**或**编辑**，先选**模板／类型**，再填写对应字段。
模板说明只是提示，不会变成默认秘密；保存模板只存字段结构，不存实际凭据内容。

### 通用步骤

1. 为测试条目使用明确的合成标题，例如 **demo-server**。
2. 选择正确类型／模板，只填所需字段。
3. 秘密保持隐藏；必须视觉核对且无人旁观时才点**显示**。
4. 用标签／备注说明用途，不额外塞入秘密。
5. 展开**高级**，设置敏感度、到期、轮换、收藏、图标／颜色及精确环境变量名。
6. 查看对应字段的校验提示；弱密码评分本身不阻止保存。
7. 选**保存**或 Ctrl/Cmd+Enter；离开时明确点**取消**，Escape 不会静默丢弃秘密草稿。
8. 用保存后的摘要验证修改对象，不打印密码验证。

### 各类型字段

| 模板／类型 | 字段与边界 |
|---|---|
| 登录 | 用户名／邮箱／手机、密码、网站与可选 TOTP |
| SSH（密码） | 主机、可选独立 IP、端口、用户名、登录密码 |
| SSH（证书／私钥） | 主机／IP／端口／用户名、多行 PEM／OpenSSH 私钥、可选 OpenSSH 用户证书与私钥口令 |
| API Key | apiKey、可选 URL／账号；演示可用 **demo-api** |
| OAuth | access／refresh token、到期、相应 client／scope／token URL 元数据 |
| TOTP／Google 验证器 | 标题与 Base32 设置密钥或单账号 otpauth://totp/ 链接，不要求登录密码 |
| 银行卡 | 卡号、到期、CVV、持卡人；显示／导出均敏感 |
| 通用 Secret | 一个秘密及用途说明 |
| Cookie | 用会话页捕获／导入／管理；会话 cookie 不等于登录密码 |
| 自定义 | 额外字段；未修改的嵌套原始数据保留，不应静默字符串化或丢失 |

SSH 示例主机用 **example.com**，文档保留 IP 用 **192.0.2.10**，端口 **22**。
“证书”是 **OpenSSH 用户证书**，不是 TLS。基本私钥格式校验不连接服务器、不证明该 key 被接受。
切换 SSH 认证可能移除不再适用的密码／私钥草稿，应核对明确确认。普通编辑不应丢失原 TOTP 与无关已存字段。

### TOTP 注意事项

- 填长期设置密钥，**不是**手机正在显示的六位验证码。
- 当前支持 URI 的 SHA-1 算法；支持链接中的位数、周期、发行者、账号信息保留。
- 编辑器不支持二维码图片及 Google 验证器 **otpauth-migration://** 多账号迁移包。
- 其他凭据类型也有独立两步验证区；缺少登录密码不影响仅 TOTP 条目。
- 设置链接会泄漏种子；仅需登录验证码时，不应复制设置链接。

### 附件与历史

私钥、证书、恢复文档仅在获准保存时添加。附件是加密条目内的 base64 内容，不是公开下载 URL。
下载会创建新的明文文件；从当前条目移除附件不会擦除历史备份／云快照。
旧密码可能仍在别处有效，不要无谓放入截图或事故报告。

## 快速导入

从**首页／密码簿 → 快速导入**或命令面板打开。真实批量凭据**只在此处粘贴**，不要发进聊天。
这是 GUI-only 遮罩预览／确认流程，不是要求模型接收整段密码的工具。

### 格式与示例

默认格式：

~~~text
{user}@{host}:{port}|{pwd}|{tag/nick_name}
~~~

合成示例：

~~~text
deploy@example.com:22|DEMO-NOT-A-REAL-PASSWORD|demo-server
operator@192.0.2.10:2200|DEMO-SECOND-NOT-REAL|demo-alias
~~~

冒号后是**端口**，不是 IP。host 本身可为主机名或 IP；别名与真实 IP 分开时选 host-IP 预设。
选择主机:端口、仅主机、主机:IP、IP:端口预设，不要期待解析器猜测。
默认主机:端口格式即便使用默认端口也要保留冒号；不想写冒号请选择仅主机。

| 占位符 | 含义 |
|---|---|
| {user}／{username} | 用户名 |
| {host} | 主机名／IP；IPv6 后跟端口需方括号 |
| {port} | 端口；可设默认 SSH 端口，否则为 22 |
| {ip} | 独立真实 IP，绝不猜成端口 |
| {pwd}／{password} | 密码，保留首尾空白与 Unicode |
| {tag}／{tags} | 逗号分隔标签 |
| {nick_name}／{nickname}／{title} | 显示标题 |
| {tag/nick_name} | 整个末尾字段同时作一个标签与标题 |

反斜杠转义下一个字符，真实分隔符写成 \|，真实反斜杠写成 \\。
引号是普通内容，不是 CSV 引号，不能保护未转义分隔符。
忽略空行与整行 # 注释；单批最多 **500 条／1 MiB UTF-8**。

### 预览 → 选择 → 确认

1. 选择格式、类型、默认端口，粘贴内容。
2. 点**解析预览**，核对原始行号、主机／IP／用户／端口／标签及状态；只显示密码是否存在，**不显示值**。
3. 修正错误行；重复身份禁选／跳过，不会静默用新密码覆盖旧条目。
4. 只选择确实要保存的有效非重复行。
5. 进入确认步骤，明确确认所选数量。
6. 检查新增／跳过结果；成功后输入清空，别因列表有筛选就重新粘贴导入。

重复身份考虑类型、主机、IP、端口、用户名；这不是替换现有密码操作。
预览能力只在内存保留 **5 分钟**；改输入／重新预览、锁库、换库、改权限或关闭插件会撤销。
陈旧预览必须重新解析。确认结果不确定时先检查，保留原确认上下文，不要启动第二次独立导入。

## 安全检查与在线泄漏隐私

从首页或命令面板打开**安全检查**。

1. 查看整体评分、弱／重复密码、缺少 2FA、HTTP URL、轮换／到期列表。
2. 点报告条目／徽标定位对应凭据，先识别目标再修改。
3. 合并前核对重复组；合并改变数据，不确定时先备份。
4. 仅向已授权路径导出库存／安全报告；即便不含秘密，也会暴露标题与服务使用情况。
5. 评分只辅助筛查；无问题不等于渗透测试通过或账号绝对安全。

### 在线泄漏检查

发起泄漏检查时，阅读在线／离线确认。在线向 **api.pwnedpasswords.com** 发送 **SHA-1(password) 的前五个十六进制字符**并附 Add-Padding，在本机匹配后缀。
不发送密码、完整哈希或条目身份，但服务／网络路径能看到 IP 与哈希前缀桶。Padding 降低响应大小信号，**不隐藏**这些事实。
离线只用内置常见密码表、不会发该请求，但覆盖更少；缓存／常见表命中可能不联网。
合成“泄漏”条目的截图不能证明真实密码已被检查。

## 导入／导出

打开**导入／导出**。路径指 **DSH 宿主**文件，不是另一台只显示 GUI 的设备上任意文件。

### 安全导入

1. 大量迁移前先做本地加密备份，核对当前目标库。
2. 选择来源：浏览器、1Password 1PUX／旧 1PIF、Bitwarden JSON／密码保护 JSON、KeePass KDBX／XML、Enpass、管理器 CSV。
3. 有**预览**时优先预览，在本地输入文件路径和必要的源密码／keyfile。
4. 核对解析数量与身份摘要；预览不代表被遮罩／缺失的原字段可以恢复。
5. 管理器 CSV 有遮罩逐行预览与明确确认；其他来源按各自预览／覆盖／确认提示执行。
6. 仅在确实更新已有匹配凭据时选择**覆盖**；预览按钮不写库，导入按钮也不代表所有来源都有逐行选择流程。
7. 检查新增／更新／跳过统计，抽样验证且不打印秘密。

Chrome／Firefox／Keychain 依赖源平台权限、加密／钥匙串状态及需要时的源主密码；不要不看请求就反复同意系统提示。
KeePass XML 中 ******** 遮罩值不能凭空恢复。迁移／恢复验证完成前妥善保留受保护的源文件。

### 导出警告

**CSV、1Password 1PUX、普通 Bitwarden JSON、浏览器 CSV、KeePass XML、env 文件和 cookie 导出可能含明文秘密；ZIP 容器不是加密。**

1. 有意选择路径；宿主写入位置可能不在浏览器下载目录。
2. CSV 仅选所需字段／条目；去掉密码列不等于其他元数据都无害。
3. 阅读明文警告，仅确认获准的导出。
4. 限制访问、排除 Git／同步目录，使用后删除临时明文。
5. 加密便携备份应使用独立密码的加密库导出入口／工具，不要把相似名称的明文迁移按钮当成它。

## 云端同步：配置、预览与合并

打开主入口**云端同步**。它是四通道加密**条目快照**系统，不是旧版原始库文件上传器。

### 先理解上传内容

- 快照包含**全部条目**，含回收站、历史密码、cookie 与附件，用**独立通道同步密码**加密。
- **不是原始加密库文件的直接副本**；设备可有不同本地主密码，但要使用与快照匹配的同步解密材料。
- 不导出无关 DSH 宿主设置、插件、MCP 或对话会话配置。
- 信封／索引仍有明文 ID／时间／哈希、通道、库／设备名、平台／版本／分区信息；命名不要敏感。
- 加密共同祖先／基准用于三方比较，不是远端账号凭据。
- 通道鉴权和同步密码存 **DSH 宿主凭据槽**，不自动成为 1pass 条目。

### 配置与保存

1. 选通道卡片，打开配置框；只编辑**打开它的通道**，不是四通道一起改。
2. 填目标与遮罩鉴权字段。已存秘密显示“已配置／已保存”，不会把真实 token 作为表单值返回。
3. 等待保存回执／使用界面提供的保存按钮。有些目标变更去抖自动保存；**关弹窗不等于上传**，失败／未保存不能算成功。
4. 在安全卡中设置／保存加密、解密密码。另一设备用匹配同步密码；不要默认它等于本地主密码。
5. 选择密码库分区，保持强制加密；不提供明文上传。
6. 测试／刷新并读警告；可读探测成功**不等于**有写权限。

| 通道 | 字段／鉴权／命名空间 |
|---|---|
| Git | 仓库 URL、子目录（默认 **1pass**）；HTTPS token 或现有 SSH key／agent。分支默认从远端 HEAD 自动识别，可显式配置。 |
| WebDAV | HTTPS endpoint、用户名、密码、前缀（默认 **1pass**）；测试可能创建所需目录，不保证完全无副作用。 |
| S3 | provider、endpoint／region、bucket、prefix、access-key id、遮罩 secret、寻址／方言；确认 endpoint 属于目标服务。 |
| Gist | Gist ID、token、可选 API base、文件前缀（默认 **1pass**）；公开 Gist 会公开元数据／密文，优先私密目标。 |

### GitHub 登录与仓库选择

Git 配置可提供 **GitHub 设备授权**、私有仓库选择／创建，同时保留手填 URL／token。
只对目标账号发起登录，打开显示的验证网址，由**用户本人**完成批准；设备码和鉴权界面也应谨慎对待，不发进聊天／issue。
等待已配置／已认证结果，再列仓库，保存前核对 owner、私有仓库与 URL。
新建私有仓库是远端写操作，应有意确认。登录或选仓库本身不会上传密码库。
SSH URL 使用宿主现有 SSH 环境，不会自动读取 1pass 的 SSH 条目 token。严格主机密钥检查失败时修复宿主环境，不要禁用检查掩盖错误。

### 手动推送

1. 核对通道、目标、密码库范围与已存同步密码。
2. 打开**推送预览**，审阅范围／数量与可见元数据。
3. 只有目标库与目的地均正确才确认。
4. 等待实际结果；配置已存、fixture 绿标或预览不证明推送成功。
5. 刷新远端快照／历史核对结果；超时效果未知时先检查再重试。

预览绑定本机内存／磁盘版本、通道／目标／选择项及**整个远端索引版本**；本地编辑或远端索引变化会使旧授权失效。
远端有未合并变更时应先同步／合并，不能强行用旧本机快照覆盖。

### 拉取、一键同步与合并

1. 刷新远端快照，选择目标最新或历史快照。
2. 拉取／同步／合并预览在宿主下载、验证与解密。
3. 核对新增／更新／冲突摘要；秘密遮罩时检查 ID／身份，不凭隐藏值猜测。
4. 选择**保留本机、采用远端**或安全的可用合并结果；密码／私钥／数组不做文本拼接。
5. 明确确认所选条目与破坏性删除提议；未确认保持本机。
6. 宿主先留安全副本，再复核本机／磁盘／远端预览事实，应用已接受修改。
7. 完整接受才推进加密基准，未决项不推进；报告完成前看 pending／conflict 警告。

远端快照历史不是本地审计。合并旧快照前先检查，区分回滚与删除远端字节。
同步后本地新编辑会使回滚陈旧，不应被静默覆盖。

### 自动同步

默认关闭、逐通道配置；核对周期、启动频率、实时本地写入去抖／远端轮询、冲突策略与自动应用档位。
首次无基准要人工操作；启动／远端轮询**只下行**，周期／本地写入触发可在配置授权下双向。
低风险档不会自动应用密码库变更；“本机优先”是明确策略，不是冲突都无害的承诺。
锁库／只读／不可用、目标改变、卸载会撤销活动能力；检查失败／跳过计数，不要默认后台已完成。

### 竞态、保留与工作目录边界

| 机制 | 实际保证与限制 |
|---|---|
| Git | fetch／ff-only／非 force push 保护分支并发；不 force push、不自动破坏性 reset、不合并无关历史 |
| WebDAV | 强 ETag 条件写索引；无可用 ETag 时有非原子窗口 |
| AWS 风格 S3 | 支持条件请求的 endpoint 可获保护，兼容性仍需运营者验证 |
| OSS | 现有索引 HEAD 后 PUT **不是原子 CAS**，中间写入仍可竞态 |
| Gist | 读／合并／PATCH／验证保留已观察事实，不能保护未观察写入，**不是原子 CAS** |
| 保留策略 | 默认最近 10 份；清理失败单独警告，不等于已成功上传被回滚 |

删除 Git／Gist 文件不清历史密文，对象版本／备份也可能保留。清理快照不等于加密擦除。
Git 出错先看**受管工作目录事实**。重新关联只改 origin；确认接管要求干净、可快进；**重新克隆会丢弃未推送／本地工作**，必须明确确认。不要为了变绿就删未知目录／陈旧锁或 force push。

## 本地备份与旧版云备份

从首页或命令面板打开**本地备份**。

1. 创建备份，核对时间与所属库。
2. 查看可用副本，识别当前日期命名与旧版命名。
3. 点**恢复**，辨认**合并**与**替换**：前者把条目复制进当前库，后者在安全副本之后覆盖整库。
4. 只有要更新冲突条目时才选覆盖。
5. 核对恢复后的摘要／数量，做小范围授权抽样。
6. 确认有其他已测恢复路径才删备份；删除一份不会删除全部独立副本。

本地备份复制原始加密库文件，需要对应主密码；云同步条目快照格式与同步密码不同。
**旧版云备份（仅迁移）**保留单向 GitHub Contents／S3／OSS／R2，既不是当前双向同步，也不建立合并基准；四通道不自动继承旧目标授权。
旧格式恢复参阅[旧版备份指南](<cloud-backup.md>)，不要改名冒充新同步快照。

## 设置、密码库、权限与恢复

### 命名库

1. 创建／切换／重命名／删除前先检查活动库标记。
2. 仅操作预期名称；相近文件名不是访问其他账号库的许可。
3. 重命名时活动库跟随；同步状态有身份映射，不应只因改名就丢共同基准。
4. 删除必须有明确意图；default 库受保护。删后重建相同名称不会自动继承旧上传授权。
5. 破坏性库操作前备份；条目回收站不能单独恢复被永久删除的库文件。

### 访问与捕获

| 设置 | 含义 |
|---|---|
| ask | 默认。普通读取自由，受保护模型写入询问；**不是读每个密码都确认**。 |
| readonly | 仍可读取／搜索／TOTP，工具和 GUI 受保护修改被拒绝；不是仅元数据或 OS 隔离。 |
| auto | 普通读写不逐次请求写入审批，只用于可信工作流。 |
| 自动捕获 | 默认关闭，按用户意愿建议保存主动分享的凭据，不是搜集秘密许可。 |
| 自动锁定 | 从不／1／5／15／30 分钟／1 小时，控制运行时闲置锁定。 |

高敏条目的按 ID 模型读取（如 vault_get）在 ask／auto 下有额外运行时审批；不是全部批量／导出／CLI 路径统一闸门。不要用 vault_fill 绕过被拒绝或缺失的安全读取。
GUI 直接操作执行自身确认／只读规则；工具目录不是操作系统边界。

### 模型工具档位

- **基础 Basic：11** 个核心工具。
- **标准 Standard：64** = 核心 + 53 管理。
- **完整 Full：113** = 核心 + 管理 + 27 导入导出 + 8 会话 + 14 文件。
- **自定义 Custom：** 核心始终保留，只选需要的可选组。

即时生效并保存在库目录 tools.json；工具目录是**进程级**，不是每个命名库独立隔离的一份。改档不授予目标／网络权限。

### 恢复码控件

访问／实用操作区提供**生成恢复码、验证恢复码**，可能出现在密码簿底部实用／状态控件中，而非独立设置子页。
准备好离线保管才生成；重新生成会使旧码失效。程序只存 SHA-256 哈希，用于验证持有。
**它不能解密忘记主密码的库、导出主密钥或重置主密码。** 验证成功不会解锁；保管真实主密码与已验证备份。
OS 钥匙串／helper-command 托管仍是[设计草案](<master-key-custody.md>)，不是已经实现的 GUI→CLI 自动解锁。

## 标签

1. 在密码簿选标签筛选或打开**标签管理**。
2. **重命名／移除标签**前先核对条目数。
3. 重命名影响当前库匹配条目；移除标签**不会删除条目**。
4. 设置页也提供标签摘要／重命名捷径；多选可向选中条目添加标签。
5. env 标签有实际意义：决定批量 CLI 环境变量导出范围，不要随意加给所有条目。

标签、标题、备注可搜索／展示，不要放密码或私有基础设施秘密。

## 会话

这里保存 cookie 凭据，不是 DSH 对话会话。打开登录窗口需要宿主的可选 playwright-core 与可用浏览器。

### 手动登录 → 收集 → 保存 → 关闭

1. 输入已授权 URL，例如 **https://example.com**，选择**打开**。
2. 在插件打开的窗口中，由用户**手动**完成登录、2FA 与 captcha。
3. 返回 1pass，为打开会话填写明确标题。
4. 点**收集／保存**，核对 cookie 数；零表示没有收集到可用 cookie，不能说账号会话成功。
5. 用会话关闭动作关掉不用的登录窗口；已保存 cookie 留在加密库中。

打开窗口不证明登录成功，收集 cookie 也不验证网站仍接受该会话。

### 管理已存会话

- 列表显示 cookie 数、过期／即将过期与时间，不显示值。
- 仅在获准时看详情；即便还未复制值，域名／标记／过期也可能敏感。
- 只向目标消费程序导出 **Cookie header、Netscape jar、Playwright** 数据／代码；剪贴板内容是明文账号访问材料。
- 导入时粘贴支持的 JSON／原始 Cookie header 并填标题；这是秘密输入，不是用来发聊天排错的附件。
- **清理**需确认移除过期 cookie；没有固定过期的 session cookie 保留。
- 不用时删本地会话；清理／删除不撤销服务端会话，需时另用网站退出／撤销功能。

## 活动、历史与回收站

### 活动／历史

点活动／历史图标或首页入口，按**全部／读取／搜索／写入**或具体操作筛选，需要时加载更多。
事件记录操作、标题／ID 与时间而非秘密值；是近期进程活动，不是持久化防篡改审计、远端登录或云成功证明。
区分**历史密码**（含旧秘密）、**本地活动、备份、远端快照历史**，不要混为一谈。

### 回收站

1. 打开**回收站**，识别删除条目。
2. 单条选**恢复**，或恢复当前库全部回收站条目。
3. 只有审阅永久删除确认后才用**永久清除／清空回收站**。
4. 完成后核对活动列表与回收站数量。

软删除条目仍加密存在库内，也包含在完整云条目快照中；清除当前条目不会擦除旧本地备份、云快照或 Git／Gist 历史。

## 助手与 CLI 的安全交接

通过 DSH 正常 Skills UI 导入仓库的 [/1pass 技能源码](<../skills/1pass/SKILL.md>)；仅安装插件不会安装本地技能。

~~~text
/1pass demo-server
/1pass demo-server only host username port
/1pass use demo-api for authorized task
~~~

遵循**摘要 → 消歧 → 选定 ID、即时最小字段 → 已授权消费程序 → 验证真实结果**。
不要用匹配直取／整条读取绕过被拒绝或不可用的安全读取；搜索成功不能说“SSH 已连接”。
已安装 CLI 的 dsh-vault get demo-server --field host 仅取单个元数据字段；秘密由消费程序内部读取，不记录 stdout、不放 URL／进程参数。
CLI 主密码来源为 --password-stdin、DSH_VAULT_MASTER_PASSWORD、DSH_VAULT_PASSWORD、再交互输入，不自动共用 GUI 密钥。
--mask 有时保留前缀，自定义／元数据可能不遮罩；同时给 --all 仍输出完整条目。优先显式 --field 或 env --keys-only，不把遮罩当通用保密屏障。
[CLI 与环境变量说明](<../README-zh.md#命令行>)有入口、引号与输入要求。

## 排障与结束检查

| 问题 | 安全处理 |
|---|---|
| 已知条目不见 | 先清筛选／搜索、核对活动库，不立即重建重复条目 |
| 导入预览过期 | 重新解析／选择，不复用旧 token |
| 只读阻止导入／编辑 | 请用户有意改策略，不经另一工具绕过 |
| 云显示已保存但无快照 | 保存配置不等于推送；做已审阅预览／确认并检查远端结果 |
| Git 可读但 push 失败 | 检查写范围／分支／工作目录，不 force push、不删未知目录 |
| 同步变化／冲突警告 | 刷新本机远端状态，重新预览 |
| 登录窗口未认证 | 用户完成登录，分别核对 cookie 数与真实消费结果 |
| 恢复码未解锁 | 符合设计，持有验证不是解密 |
| 语言不对 | 改 DSH 宿主 locale 再返回，不找条目级语言字段 |

离开前：保存或明确取消草稿、关闭手动登录窗口、删除不用的明文导出、核对操作结果，必要时锁定密码库。
