# 新增凭据与快速导入（1.11.1）

## 按类型填写，而不是统一的大表单

在 设置 → 密码管理(1pass) → 新建条目，先选择「套用模板」或「类型」。选择保持在下拉框中，模板决定实际显示和保存的字段，模板描述只是输入提示，不会作为密码或其他默认值入库。

- 登录：用户名、邮箱/手机、密码、网址、两步验证等账号字段。
- SSH（密码）：主机、可选 IP、端口、用户名、登录密码。
- SSH（证书／私钥）：主机、可选 IP、端口、用户名、私钥、可选 OpenSSH 用户证书、可选私钥口令。
- API Key、OAuth、银行卡、通用 Secret、自定义等各有对应字段；高级元数据折叠显示。

这里「证书」区分于密码登录，主要通过私钥认证。私钥支持 PEM/OpenSSH 多行文本；可选 certificate 字段是 OpenSSH 用户证书，不是 TLS 网站证书。私钥与口令默认隐藏。界面只做基本文本形状检查，不代表私钥已验证可登录服务器；不会连接服务器。

新 SSH 条目需主机、用户名及对应认证内容，端口为 1–65535；弱密码不按强度阻止保存。切换认证方式时，删除已有密码/私钥前会要求确认。旧条目的额外字段不会在普通编辑时无声丢失；未修改的嵌套自定义字段保留原类型。

保存为模板只保存字段名称，不保存实际密码、私钥、卡号、CVV、备注或自定义字段值。旧模板的描述不会被当作数据。

## TOTP / Google 验证器（1.11.2 恢复）

新增凭据的模板下拉框与快捷按钮提供「TOTP / Google 验证器」。可只填标题与验证器设置密钥，无需登录密码；其他类型也都有独立可见的「两步验证」区块，不再因字段筛选而被隐藏。已有 TOTP 数据与 SSH 认证切换时保持不变。

支持粘贴 Base32 设置密钥，或 `otpauth://totp/...` 单账号设置链接（Google 验证器常用的 SHA-1）。不是手机正在显示的 6 位临时验证码。链接中的位数、周期、发行者与账号信息原样保留。密钥默认隐藏，不写入模板、日志或浏览器存储。

二维码图片、Google 验证器 `otpauth-migration://...` 多账号迁移导出暂不支持；界面明确提示，不会把这些内容错误保存成可用密钥。当前引擎为 SHA-1，其他算法的设置链接会被明确拒绝，避免生成错误验证码。

## 快速导入

入口：工作台首页或密码簿的「快速导入」按钮，也可从命令面板打开。

默认格式：

    {user}@{host}:{port}|{pwd}|{tag/nick_name}

示例（仅合成测试值）：

    root@192.0.2.10:22|TEST-NOT-REAL|demo
    deploy@server.example:2200|ANOTHER-TEST-VALUE|production-alias

此处冒号后是 SSH **端口 port**，不是 IP。{host} 可以直接填写 IP 或主机名；若要把主机别名和实际 IP 分开保存，选择 host-ip 预设并显式使用 {ip}。

### 占位符与分隔符

- {user} / {username}：用户名。
- {host}：主机名或 IP；IPv6 后跟端口时需方括号，例如 [2001:db8::10]:22。
- {port}：端口；SSH 预设留空时采用所填默认端口，未指定则 22。
- {ip}：单独的实际 IPv4/IPv6 地址，绝不猜测成端口。
- {pwd} / {password}：密码，保留首尾空格、Unicode，不按强度检查。
- {tag} / {tags}：逗号分隔多个标签。
- {nick_name} / {nickname} / {title}：显示名称。
- {tag/nick_name}：整个最后字段同时作为一个标签和显示名称，不按逗号拆开。

自定义格式必须包含用户名、地址和密码，不能使用任意正则或代码。格式预设有「主机:端口」「仅主机」「主机:实际IP」「IP:端口」。

反斜杠转义下一个字符：密码中的竖线写成 \|，真实反斜杠写成 \\。例如密码实际为 ab|cd\ef 时，输入为 ab\|cd\\ef。引号只是普通字符，不是 CSV 引号；即便加了引号，分隔符仍须转义。

默认端口格式仍需冒号：root@host:|pwd|label。若不想写冒号和端口，请选「仅主机」预设 root@host|pwd|label，不会隐式猜测整行。

空行和整行 # 注释忽略，错误行保留原始行号。单次最多 500 条、UTF-8 1 MiB。只含 IP 的规范遵循标准地址格式，主机名使用 ASCII/punycode；用户名、密码、昵称与标签支持 Unicode。

### 先预览，再确认写入

1. 选择格式、SSH 密码或登录类型，粘贴多行内容。
2. 点击解析预览。预览不返回密码，只显示是否有密码、主机、用户名、端口、标签和逐行状态。
3. 重复项禁选；错误行不会保存。勾选需要的有效行，核对后进入确认步骤。
4. 明确确认后保存，一次原子写入加密库。重复身份按类型、主机、IP、端口和用户名判断，不覆盖原密码。
5. 看新增／跳过数量；成功后输入内容清空。请求结果不确定时仅重试原确认，不自动重新导入。

预览只在内存中保留 5 分钟；修改输入、重新预览、锁库、换库、改权限或关闭插件会撤销能力。只读、锁定、未解锁时不能确认导入。导入内容、预览 token 不写入浏览器存储、URL、模板或日志。

## 安全边界

本修复没有改变 1.11.0 的模型读取授权模式。ASK 仍主要是写入前询问，不等于每次读取密码都询问。快速导入是 GUI-only 接口，不注册让模型接收整段批量密码的导入工具。不要把真实批量密码粘贴到聊天；在设置页输入。
